# 🌿 UltraCool: Urban Heat Island Prediction using Machine Learning

## 📌 Project Overview

UltraCool is a machine learning project that predicts Land Surface Temperature (LST) using environmental, meteorological, spatial, and land-cover features.

The project analyzes urban heat patterns in Surat, Gujarat, and identifies the key factors contributing to Urban Heat Islands (UHI).

---

## 🎯 Objectives

- Analyze urban heat patterns
- Perform comprehensive exploratory data analysis
- Train multiple regression models
- Compare model performance
- Identify the most influential environmental variables
- Support sustainable urban cooling strategies

---

## 📊 Dataset

- Study Area: Surat, Gujarat
- Period: 2015–2023
- Records: 34,884
- Features: 15

---

## 🤖 Machine Learning Models

- Linear Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost

---

## 🏆 Best Model

### Random Forest Regressor

**Performance Metrics:**

- **MAE (Mean Absolute Error):** 0.719°C
- **RMSE (Root Mean Squared Error):** 1.001°C
- **R² Score:** 0.898

---

## 🌍 Key Findings

- **NDBI (Normalized Difference Built-Up Index):** The most influential predictor of urban heat.
- **NDVI (Normalized Difference Vegetation Index):** Vegetation helps reduce urban heat.
- **Water occurrence:** Proximity to or occurrence of water bodies significantly lowered surface temperatures.
- **Built-up regions:** Consistently exhibited the highest surface temperatures.
